# Dataset Folder

- `hflights_raw.xlsx` — original source file (Houston 2011 flights dataset).
- `raw_dataset.csv` — raw dataset exported from the source file, unmodified (227,496 rows × 21 columns).
- `cleaned_dataset.csv` — **TODO:** output of the Power Query cleaning/transformation steps (missing values handled, data types fixed, derived columns added, etc.). Export this from Power BI / Power Query once cleaning is complete.

## Raw dataset columns
`Year, Month, DayofMonth, DayOfWeek, DepTime, ArrTime, UniqueCarrier, FlightNum, TailNum, ActualElapsedTime, AirTime, ArrDelay, DepDelay, Origin, Dest, Distance, TaxiIn, TaxiOut, Cancelled, CancellationCode, Diverted`
